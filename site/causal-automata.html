Three ideas this toy universe keeps apart

01 / STRUCTURE

A causal set, with scaffolding

Each update is an event. Define A ≺ B when a directed dependency path reaches B from A. On this infinite spatial lattice that is exactly Δt > 0 and |Δx| ≤ Δt.

This is a locally finite partial order. But the lattice, left/right roles, and synchronized clock are built in. The bare order alone does not supply the input roles needed to evaluate Rule 30.

It is not a Lorentz-invariant sprinkling or emergent gravity. Erasing labels does not erase preferred lattice structure.

02 / INFLUENCE

Permission is not propagation

The mint cone is the possible future. Orange cells are an actual difference between two histories. Different rules can propagate, mask, or cancel a disturbance inside the same cone.

Rule 30 always responds to flipping L alone. It responds to flipping C only if R = 0, and R only if C = 0. Rule 150 responds to every single-input flip, but changes arriving on multiple paths can cancel by XOR.

A cone bounds influence; it does not specify a law. The experiment measures a particular intervention, not every possible message or information channel.

03 / PREDICTION

Complexity is not randomness

Rule 30 plus a one-bit seed is a short description of a complicated picture. Apparent randomness is not proof of algorithmic incompressibility, and universal “no shortcuts” claims for Rule 30 are not established here.

The reveal slider uncovers a precomputed history; moving it backward does not invert the dynamics. Both all-zero and all-one rows evolve to all zeros under Rule 30, so it is not globally reversible on an infinite or periodic lattice.

Predictability, reversibility, low-entropy initial conditions, and the orientation of causal order are separate questions.

Under the hood: truth tables, boundaries, and what this does not prove

Each output is computed from the previous row’s left (L), center (C), and right (R) bits. These Boolean rules use all three inputs as potential dependencies.

The displayed window is x = −40…40 and t = 0…48. Computation includes 48 extra initial cells on each side: enough to calculate every displayed event without artificial wraparound or edge effects. Random initial bits are a reproducible hash of seed and spatial coordinate; this is not physical or cryptographic randomness. Some causal ancestors and descendants lie outside the displayed window.

The graph shows a small crop of the same dependency lattice in both histories. We do not infer dimension from the images or compute a continuum-limit action. There is no stochastic sprinkling, quantum dynamics, varying causal geometry, or thermodynamic entropy measurement in this laboratory. Comparisons with manifold-like causal sets would require separate diagnostics.

The next research question: what changes if a rule creates the events and their order, instead of merely changing states on this fixed order? That is a different experiment, closer to causal growth—and it must confront label independence and manifold-likeness.
